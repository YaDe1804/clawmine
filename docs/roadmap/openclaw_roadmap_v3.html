Projekt-Philosophie

OpenClaw ist ein reines AI-Gateway + Memory/RAG Backend — keine eingebauten Messenger. Messaging läuft über AntarBridge (eigene Entwicklung, in Arbeit). Embedding und Memory vollständig lokal über Ollama/bge-m3 — keine Cloud-APIs, keine externen Abhängigkeiten. Platform: Windows + Linux. Security First. Enterprise Grade.
